# PROJECT MASTER PROMPT — Belentani: The Experience

## Identidad
Belentani: The Experience es el sitio central del artista BELENTANI y su universo narrativo. Judas Era es el Canon 0; las experiencias históricas se conservan como referencias, no se presentan como proyectos fusionados.

## Visión
Unir música, identidad, visualidad y narrativa en una entrada artística clara, rápida y memorable, con una experiencia inmersiva que también funcione para quien necesita una navegación convencional.

## Alcance
- portada y hero interactivo;
- capítulos Genesis, Traición, La Deuda y Redención;
- música, biografía, enlaces oficiales y lore;
- accesibilidad, SEO, responsive y rendimiento;
- separación entre contenido público, archivo y material privado.

## Límites
No inventar créditos, lanzamientos o colaboraciones. No exponer claves, archivos privados ni rutas internas. No usar efectos visuales que impidan comprender o navegar el sitio.

## Arquitectura
Frontend web con carga progresiva de Three.js/assets, fallback HTML accesible, rutas estables, optimización de imágenes, pruebas UI y despliegues reproducibles.

## Fases
1. base artística estable;
2. navegación narrativa;
3. música y capítulos;
4. optimización visual y móvil;
5. SEO, accesibilidad y publicación.

## Criterio de entrega
Ninguna página se considera terminada sin navegación real, responsive, fallback, metadatos, prueba de enlaces y validación del despliegue.
