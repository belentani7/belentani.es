# GitHub Pages — Desactivado

Este repositorio **no usa GitHub Pages**. El despliegue de producción se realiza
exclusivamente a través de **Vercel** (https://belentani.es).

GitHub Pages ha sido desactivado desde la configuración del repositorio para
evitar conflictos DNS y 404 en el dominio raíz.

Para reactivar Pages en caso necesario:
- Ve a Settings > Pages
- Selecciona la fuente (recomendado: `gh-pages` branch o `/docs` folder)
- Configura un CNAME solo si Vercel no controla el dominio completo
