# Patrones — belentani.es

Un patrón se escribe aquí cuando el mismo problema aparece **tres veces** o cuando la solución
tardó más de una hora en encontrarse.

## Formato

```
## Nombre del patrón
- Contexto: cuándo aplica
- Problema: qué falla
- Solución: qué hacer, con código mínimo
- Contraindicación: cuándo NO usarlo
- Evidencia: commit, issue o ruta
```

## Índice

_(vacío — se llena con el uso)_
