# BELENTANI — Artist Universe (Next.js)

Aplicación artística de BELENTANI, recuperada de la fuente local del proyecto.

## Experiencias disponibles en el código
- Inicio / — presentación y navegación editorial.
- JUDAS /judas — narrativa y capítulos.
- Galaxia /galaxia — navegación de mundos con fallback WebGL.
- Música y artista /musica y /artista.
- Galería /galeria — archivo artístico.
- Laboratorios /ai-lab y /studio-creativo.

## Desarrollo
Instalar Node.js 20+ y pnpm; ejecutar pnpm install --frozen-lockfile, pnpm typecheck, pnpm build, pnpm dev.

Esta entrega comprende la aplicación Next.js y sus fuentes, no cientos de snapshots HTML, informes ni archivos de chats. No se incorporan masters, stems, credenciales ni datos privados. Las versiones OMEGA se conservan en belentani-omega-showcase.

Procedencia: workspace local webs-reparadas/belentani.es, rama repair/public-navigation, 21-11-2026. No se declara despliegue público verificado.
