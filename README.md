# BELENTANI — The Experience

Universo artístico interactivo de Pedro Belentani. Música, narrativa, arte digital y código conectados en una experiencia visual.

Sitio: <https://belentani.es>

## Explorar

- Artist OS: puerta principal al universo.
- JUDAS: cuatro capítulos narrativos.
- Galería y archivo visual.
- Música, prensa y contacto.
- Experiencia alternativa sin WebGL.

## Uso

Instala dependencias con `pnpm install` y abre el entorno local con `pnpm dev`. Para producción, usa `pnpm build`.

No se almacenan masters, stems ni sesiones de audio en Git.
