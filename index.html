El universo

Construido para durar,
verificado para no fallar.

Experiencia pública, histórico preservado y cero dependencia de APIs de pago.

Galaxia interactiva

Three.js como lienzo: navegación por capítulos dentro de una galaxia viva, con verificación visual automatizada en desktop y móvil.

Calidad verificada

Tipos, tests y build verificados en cada entrega: typecheck, vitest, boundaries y comprobación visual con Chrome real.

Coste cero

La experiencia principal no llama a ninguna API de pago: navegación libre sin créditos, suscripciones ni rutas de pago.

Alcance público definido

Artista, música, narrativa y assets curados. El audio privado, másters y sesiones quedan fuera del repositorio por diseño.

Historial intacto

Los proyectos históricos se preservan fuera del lanzamiento público: nada se reescribe, nada se pierde.

Stack moderno

Next.js + TypeScript + Tailwind, pnpm anclado y CI con presupuestos de Lighthouse. Listo para producción.

FAQ

Preguntas frecuentes

¿Cómo ejecuto la experiencia en local?

Necesitas Node ≥ 18.17 y pnpm (anclado vía corepack): pnpm install --frozen-lockfile y pnpm dev. Para verificar todo: pnpm typecheck && pnpm test && pnpm build.

¿Navegar cuesta dinero?

No. La experiencia principal no llama a ningún modelo de IA ni API de pago: no hay créditos, suscripciones ni servicios de enrutado necesarios para verla.

¿Qué incluye el alcance público?

Artista, enlaces de música, narrativa, assets visuales curados y canales de contacto. NoiaCore, educación, consultoría y Duck son proyectos independientes; el audio privado queda fuera de Git y del build.

¿Dónde está la Judas Experience original?

Se conserva como referencia histórica en judas-experience-13898.buildaispace.app. El canon actual vive aquí.
