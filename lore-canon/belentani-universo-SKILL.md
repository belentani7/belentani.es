# Belentani — Universo narrativo (lore compacto)

## Arco central
Un narcisista que se dirige a "sus hermanos" (otros narcisistas, código rojo) porque
una de sus víctimas rompió el código: promete escribir una canción y contar el plan.
Giro: el propio narrador se revela como el verdadero narcisista/antihéroe — nació sin
belleza ni voz, aprendió a cantar y ahí entendió el daño que llevaba; ya reformado,
elige ser el antihéroe. Alguien se enamora de él, no le encuentra defecto y queda con
"una deuda impagable" que no puede destruirlo. Cierre: "vete tranquilo, pero recuérdame."

## Simbología visual fija (para prompts de imagen/portada)
- Protagonista recortado, solo piernas visibles, desierto.
- Espejo en el suelo, marco ovalado de oro viejo, terreno tipo posguerra.
- Lado bueno: libro antiguo con símbolos santos, plumas blancas, guante de cuero,
  botella de agua con corcho, crucifijo de piedra blanca (cruz normal), medio enterrado.
- Lado malo: plumas negras, botella con líquido negro, libro abierto con símbolos
  ilegibles, cadena y candado (parcialmente abierto, ambiguo), guante de hierro con
  piedras rojas, crucifijo invertido.
- Retrato "Belentani": cuerpo denso no atlético, pelo oscuro rizado voluminoso, barba
  densa, mirada melancólica-soberana, moda futurista tipo Mugler/Rick Owens, paleta
  negro-oro-violeta, luz cinematográfica de alto contraste. Arquetipo: "soberano
  melancólico" / "guardián poético" — nunca estética superhéroe ni fitness.

## El episodio "la llave" (tratamiento obligatorio)
Referencia solo de forma poética y abstracta: alguien se llevó la llave de un lugar
donde no vivía, con amenaza de volver, y la certeza de que a quien se amenaza no se
le olvida. NUNCA incluir nombres propios, bancos, marcas ni datos identificables —
solo la imagen poética.

## Uso
Al escribir una letra o concepto visual nuevo del disco, verificar que sea coherente
con este arco y esta simbología antes de fijarlo. Para la mecánica de composición
(tonalidad, rima, estructura), usar la skill `belentani-songwriting`.
